# Generative Models: VAE, GAN & Diffusion

Реализация и исследование генеративных моделей (VAE, GAN) на датасете MNIST. В банковской сфере подобные архитектуры используются для аугментации данных при дисбалансе классов (например, генерация синтетических транзакций для обучения антифрода) и анонимизации данных. 
Цель проекта — понять принципы работы DL-моделей и научиться валидировать их качество, где нет простой метрики Accuracy.


## Реализованные архитектуры
1. **Variational Autoencoder (VAE):** 
   - Выведена и запрограммирована функция потерь ELBO (Evidence Lower Bound).
   - Использован reparameterization trick для обратного распространения ошибки через стохастический слой.
   - Визуализировано 2D-латентное пространство (кластеризация цифр).
2. **Conditional VAE (Supervised VAE):**
   - Архитектура с подачей one-hot вектора метки на вход декодера для контролируемой генерации.
3. **Generative Adversarial Network (GAN):**
   - Реализованы Генератор и Дискриминатор (Conv/ConvTranspose слои).
   - Проведен анализ сходимости (loss curves) и визуальная оценка качества.
4. **GAN с Gradient Reversal Layer (GRL):**
   - Реализован кастомный autograd.Function для объединения шагов обучения G и D в один backward pass.
5. **Diffusion Model (Bonus):**
   - Реализован процесс прямого зашумления и обратного восстановления (Denoiser на базе U-Net/ConvNet).


##  Методология оценки (Validation)
Поскольку для генеративных моделей нет единой метрики (как F1 или ROC-AUC), применялись следующие подходы к валидации:
- **Количественный:** Мониторинг функций потерь (ELBO, BCE, MSE для Diffusion), анализ стабильности обучения GAN.
- **Качественный:** Построение сеток 15x15 из латентного пространства (latent space mesh) для проверки гладкости пространства и отсутствия "мертвых зон".
- **Анализ выравнивания:** Визуализация матриц внимания (attention) и латентных пространств для оценки интерпретируемости.
